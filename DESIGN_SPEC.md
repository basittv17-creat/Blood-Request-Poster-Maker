# Design specification

A Flutter CustomPainter draws both the preview and the 1920 × 1080 image on the same proportional canvas. The twelve designs use a combination of label bands, centered seals, edge rails, modular cards, gradients, and original geometric artwork. Urdu headings use bundled Nastaliq, while smaller Urdu copy uses Naskh. Phone and blood group runs use LTR direction. Labels and user copy use bounded, measured text regions and reduce font size before truncation. Rendered output still requires inspection for legibility over the full supported input range.
